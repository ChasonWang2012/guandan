# 掼蛋 - 局域网联机版

四人两副牌（108张）的局域网联机掼蛋游戏。前端 HTML + 后端 Node.js（WebSocket 实时通信）。

## 快速开始

```bash
# 1. 安装依赖（首次）
npm install

# 2. 启动服务器
npm start
```

启动后会显示局域网地址，例如：

```
掼蛋服务器已启动！
本机访问: http://localhost:3000
局域网访问: http://192.168.x.x:3000
```

## 玩法流程

1. **创建房间**：房主打开页面，输入昵称，点「创建房间」
2. **加入房间**：其他玩家打开同一局域网地址，点「加入房间」，输入房主屏幕上的房间号
3. **准备开局**：4 人全部点击「准备」，房主点「开始游戏」
4. **开始游戏**：每人 27 张牌，轮流出牌，压过上家或过牌

## 支持的牌型

- 单张、对子、三张、三带二
- 顺子（仅5张，A 可高 10-J-Q-K-A，可低 A-2-3-4-5）
- 三连对（3对连续，如 334455、QQKKAA）、钢板（2组连续三张）
- 炸弹（4~10张同点数）、同花顺（5张同花连续）
- 四王炸（2大王 + 2小王）

**炸弹层级**（从低到高）：
```
4张炸弹 < 5张炸弹 < 同花顺 < 6张及以上炸弹 < 四王炸
```
同张数炸弹比点数；普通牌型必须同类型同张数才能比较。

## 级牌与逢人配

- **级牌**：当前打几，该点数牌变大：大王 > 小王 > 级牌 > A > K > ... > 2
- **逢人配**：红桃级牌（2张）为万能牌，可替代除大小王外任意牌（组顺子/炸弹/连对等）；单独出时只按级牌本身计算
- 级牌在顺子中可当原点数（如打2时 A-2-3-4-5 仍是顺子）

## 进贡与抗贡

- **单下**（头游+末游同队）：末游向头游进贡一张除红桃级牌外的最大牌，头游还一张 ≤10 的牌
- **双下**（头游+二游同队）：两名输家各进贡最大牌，头游拿大贡、二游拿小贡，各还贡；进贡大牌者先出
- **抗贡**：进贡方（单下1人 / 双下2人合计）持有两张大王，可抗贡，由头游先出

## 升级规则

| 结果 | 升级 |
|------|------|
| 头游 + 二游同队（双下对方） | 升 3 级 |
| 头游 + 三游同队 | 升 2 级 |
| 头游 + 末游同队（单下） | 升 1 级 |

级牌序列：2→3→4→...→K→A，打过头 A 即获胜。

## 已知限制

- 断线重连：对局中断线标记为离线，暂不支持中途重连回原手牌
- 打 A 获胜判定为简化版（打到 A 后继续升则判胜）

## 端口修改

默认 3000 端口，可通过环境变量修改：

```bash
PORT=8080 npm start
```
